# HealthTracker-App

This repository contains a lightweight frontend scaffold for the HA-5 UI/UX Design task.

Tech stack: Vite + React + TypeScript + Tailwind CSS.

Getting started

1. Install dependencies:

```bash
npm install
```

2. Start dev server:

```bash
npm run dev
```

Open http://localhost:5173

What was added

- Vite + React + TypeScript project files
- Tailwind CSS configuration
- Page skeletons: Dashboard, Steps, Sleep, Nutrition, Vitals, Profile
- Reusable components: NavBar, Card, SummaryWidget, TrackerForm, Chart
